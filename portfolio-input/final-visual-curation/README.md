# Final Visual Curation Handoff

This folder is the curation-only handoff produced from a full visual audit of the 136-image `memo(1).zip` source pack.

- `ASSET_MANIFEST.md` contains the final project-by-project visual decisions, hero/home/work/case-study selections, rejection reasons, and missing-capture queue.
- `manifest.json` contains the machine-readable source-ID mapping and role/order metadata for the 55 approved images.
- The audit does **not** redesign or wire portfolio UI.
- Rejected source screenshots are intentionally excluded from the approved set.

The selected source files were also prepared as clean full-frame WebP handoff assets. The current connected GitHub writer can commit UTF-8 repository content but cannot stream local binary files into repository paths directly, so the PR records the complete deterministic selection/mapping and does not pretend that binary assets were committed when they were not.
