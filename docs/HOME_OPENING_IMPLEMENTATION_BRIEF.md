## 4. THE MATERIAL FIELD

The field is the first living material of the portfolio.

It is not a literal object.

It is not a blob, rock, statue or mesh sculpture.

It is a computational field built from the portfolio's existing rendering material:
- PixiJS;
- DOM / CSS;
- the current grid logic.

### Visual states

The field must be capable of moving between:

1. **UNRESOLVED**
   - irregular points / traces;
   - unequal density;
   - slight local drift.

2. **PRESSURE**
   - a local region gathers;
   - spacing compresses;
   - lines become more likely;
   - no explosion.

3. **PARTIAL ORDER**
   - some points find rows / columns / diagonals;
   - a grid becomes briefly legible;
   - not all matter obeys.

4. **MEMORY**
   - after the disturbance ends, one small trace of the previous state persists;
   - it fades / settles rather than resetting instantly.

5. **STILLNESS**
   - movement almost disappears;
   - composition remains alive through tiny residual tension.

### Meaning

This field seeds the entire portfolio architecture.

It contains both:
- authored / irregular matter;
- systemic / measured structure.

The full transformation happens later at the global Threshold.

The opening only reveals that both states already coexist.

## 5. INTERACTION LAW

The field notices the visitor.

It does not mirror the visitor.

### Desktop pointer

Pointer movement may create:
- local pressure;
- directional bias;
- delayed drift.

Rules:
- no 1:1 cursor following;
- no glowing cursor halo;
- no magnetic UI gimmick;
- response begins with delay / inertia;
- effect can continue briefly after the pointer stops.

### Stillness

If pointer movement remains low for a short period:

- nearby field elements become slightly more organized;
- the scene becomes quieter;
- selected traces approach the underlying grid.

Stillness is a valid interaction.

### Re-entry

New movement does not reset the field.

It perturbs the current state.

### Mobile

No hover dependency.

Use:
- touch movement where present;
- scroll energy;
- time / stillness.

Do not request:
- camera;
- motion sensors;
- permissions.

The same conceptual law must survive without them.

## 6. FIRST FIVE SECONDS

This is not a forced five-second movie.
The visitor remains in control.

The timing below describes the intended settling rhythm.

### 0.0s

Immediately visible:
- warm mineral field;
- OMAR KHAIR;
- INDEX;
- main type composition;
- material field in low-motion unresolved state.

No loader.
No blank prelude.
No route shutter over the Home.

### 0.4–1.4s

The composition settles by a small amount:
- type reaches final position / opacity;
- the field establishes slow internal pressure;
- no dramatic entrance.

### 1.4–3.5s

The field becomes sensitive to the visitor:
- pointer / touch / stillness influences local state;
- partial alignment may become visible;
- response remains subtle enough that discovery feels earned.

### 3.5–5.0s

A small amount of memory remains after interaction.

If the visitor does nothing:
- the field approaches stillness;
- a very restrained `SCROLL` cue may become visible.

Nothing auto-navigates.
Nothing screams for attention.

## 7. MOTION LAW

Opening motion hierarchy:

**residual life -> attention -> pressure -> partial order -> settle**

Do not use:
- continuous bouncing;
- floating objects;
- random particle fireworks;
- constant parallax;
- type flying in from every direction;
- perpetual cursor reaction.

Movement amplitude should remain low enough that:
- a 10 fps recording still reads;
- a still screenshot still feels complete.

### Type motion

Typography may:
- settle a few pixels;
- reveal through controlled clipping / opacity;
- shift subtly when the field reaches pressure.

Typography must not:
- become a kinetic type demo;
- constantly react to cursor position.

## 8. SOUND

**NONE in HOME / OPENING.**

Silence is intentional.

Reason:
- the opening establishes visual / interactive authorship without asking for permission;
- SERAPH earns sound later because sound is native to that work;
- global sound would make the portfolio feel like one continuous cinematic installation and reduce project-specific identity.

No mute button is needed in the Opening because nothing plays.
