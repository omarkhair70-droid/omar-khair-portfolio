# Portfolio Input Pack

`portfolio_selected_assets_webp.zip` is the curated screenshot source pack prepared for the complete portfolio overhaul.

It contains 45 selected real screenshots plus the selection manifest, organized by project:
- Bahja — 6
- Balcona — 1
- Habba — 6
- HILTECH — 7
- Nova — 7
- Teswa — 7
- Tuscanini — 5
- WaveZero — 6

The images are WebP conversions of the selected source screenshots at their original display dimensions, optimized only to make the handoff pack repository-friendly.

Codex should extract this archive temporarily, inspect the manifest and images, then copy only the final assets it uses into a normalized `public/` asset structure. The archive itself is input/source material and should not be linked from the public website.
