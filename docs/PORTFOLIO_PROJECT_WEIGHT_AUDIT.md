# PORTFOLIO PROJECT WEIGHT AUDIT

Status: **ACTIVE**
Date: 2026-09-23
Canonical direction: `docs/PORTFOLIO_ART_PRACTICE_MASTER.md`

Purpose:
Replace the old equal-lane logic with a hierarchy based on artistic / systemic weight,
distinctiveness, current evidence, and how much physical space a project deserves in the portfolio.

This file does not change public project facts. It only determines presentation weight.

---

## WEIGHT MODEL

### MONUMENT
A project can carry a full authored chapter or encounter.
It has enough conceptual, visual and/or systemic depth to justify custom pacing.

### MAJOR WORK
A substantial project with its own visual / product story, but it should not compete with every Monument
at the same scale.

### ARTIFACT / STUDY
A useful fragment, origin, experiment, client delivery or supporting proof.
It belongs in the archive / contact-sheet layer unless later evidence justifies promotion.

### HOLD / RE-INSPECT
Do not remove automatically.
Keep out of the primary sequence until current evidence is visually inspected.
