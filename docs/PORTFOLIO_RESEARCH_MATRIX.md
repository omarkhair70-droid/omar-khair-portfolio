Status: **ACTIVE SUPPORTING RESEARCH**

- state what must not be copied;
- compare it against Omar's actual body of work.

## CURRENT BASELINE

Current portfolio thesis:
- Systems with a pulse;
- editorial precision;
- strict grid;
- product evidence;
- controlled motion;
- PixiJS signal field;
- GSAP route shutter;
- project colour;
- conventional Work lanes.

Strength:
- clear authorship already exists;
- real proof is strong;
- implementation / QA discipline is mature.

Limit:
- information architecture still reads primarily as a high-end professional portfolio;
- Work taxonomy makes projects feel like categories in a service practice;
- project weights are not yet expressive enough;
- current identity predates the Fine Arts / creative-technology shift and SERAPH.

## REFERENCE 01 — NICCOLÒ MIRANDA

Source:
- https://www.niccolomiranda.com/
- Awwwards editorial coverage.

Principle:
A portfolio can become a designed object with a metaphor that controls typography,
navigation and pacing.

Transferable:
- identity visible before project comprehension;
- typography behaves as composition;
- navigation feels part of the authored world;
- work can change visual grammar between chapters.

Do not copy:
- newspaper metaphor;
- exact condensed/editorial styling;
- horizontal work interaction.

Question for Omar:
What physical / conceptual object is native to Omar's own practice?
Possible answer may not be an object at all; it may be a change of material state.

## REFERENCE 02 — BRUNO SIMON

Source:
- https://bruno-simon.com/

Principle:
The portfolio can itself be sufficient proof of the maker's creative / technical identity.

Transferable:
- visitor learns through behaviour;
- technical ability is experienced, not listed;
- interaction creates first-memory.

Do not copy:
- game world;
- vehicle metaphor;
- gamification.

Question for Omar:
Can the first interaction demonstrate the central idea "one practice, multiple material states"?

## REFERENCE 03 — DAVID HECKHOFF

Source:
- https://www.awwwards.com/sites/david-heckhoff-portfolio

Observed field:
- creative developer;
- animation;
- WebGL;
- GSAP;
- Three.js;
- Blender;
- responsive personal portfolio.

Principle:
Creative-development craft can be embedded in a distinct visual world without being shown as a
technology inventory.

Transferable:
- strong visual object as identity carrier;
- 3D can be personal rather than product-demo-like;
- technical stack can disappear behind experience.

Do not copy:
- hologram / landing styling;
- tool-driven feature density.

Question for Omar:
Does the portfolio need its own 3D object, or can transition between 2D/material/system states
carry more identity?

## REFERENCE 04 — AWWWARDS INTERACTIVE / ART FIELD

Sources:
- https://www.awwwards.com/websites/art/
- https://www.awwwards.com/websites/interactive-portfolio-examples/
- current 2025 / 2026 nominees and winners.

Principle:
The contemporary ceiling is not "lots of animation".
It is consistency between concept, typography, motion, media, transition and responsive execution.

Transferable:
- scene transitions instead of generic page transitions;
- major works can have individual grammar;
- mobile must remain authored;
- 3D/WebGL works best when concept requires it.

Do not copy:
- current visual trends;
- fashionable typography without relation to content;
- shader / cursor / scroll effects as decoration.

## REFERENCE 05 — SERAPH (INTERNAL REFERENCE)

Source:
- `omarkhair70-droid/seraph`
- `docs/SERAPH_MASTER_BRIEF_2026-09-21.md`
- `docs/SERAPH_CINEMATIC_EXPERIENCE_MASTER_2026-09-22.md`

Principle:
Interaction changes the world, not just the UI.

Transferable:
- encounter before explanation;
- scarce motion;
- sound as architecture;
- camera / space can participate;
- still-frame quality;
- no demo feeling;
- technology admitted only when it changes human interaction.

Do not copy:
- wireframe relic aesthetic;
- black chamber;
- SERARA voice / lore;
- exact cinematic sequence.

This is a behavioural reference, not a site-theme reference.

## REFERENCE 06 — THE RED THREAD (INTERNAL ART REFERENCE)

Source:
- Omar Khair / The Red Thread / 2026.

Principle:
Technology can be part of the conceptual material, not just production infrastructure.

Transferable:
- repetition, instability and reconstruction can carry meaning;
- a recurring visual motif can change meaning across a sequence;
- an authored series does not need to explain every image before it is felt.

Do not copy:
- literal red thread into portfolio UI;
- gallery-submission layout;
- artwork subject as site metaphor.

Question:
Can a portfolio transition motif evolve meaning across Worlds -> Threshold -> Systems
without becoming branding decoration?
